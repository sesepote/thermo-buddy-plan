# Thermocycler Trainer

Planifícame una app que sea un simulador de termociclador de laboratorio que tenga un menú principal con las diferentes opciones, y las opciones que son una pantalla de termociclador estandar, con sus funciones típicas y diseño, luego otro que sea una calculadora de configuraciones de termociclador, que pueda crear los procesos completos con sus temperaturas, tiempos, ciclos, etc basandose en las opciones de entrada como diferentes reactivos, compuestos, químicos, etc, y otro más que sea como una zona de entrenamiento, que te pida un proceso, lo configuras y verifica si está bien
